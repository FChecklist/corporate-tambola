# Run log, 24-25 October 2026 (Corporate Tambola)

Written from the real run files in `data/`. Nothing is rounded up. Quality numbers: see `QUALITY_REPORT_c25f_c25d_c25c_s250a_s250b_s250h_s500a_s500h_s1000a_s1000h_s1000h2.md`.

## What was run
- Final-code campaign **c25**: 16 games of 100 people (10 to 100 players), every verify option, every way of playing (auto 9 s, auto 12 s, Host presses), with late joiners, reloads, offline phones, wrong claims and slow phones.
  14 of the 16 passed every check. Cases 5 and 15 failed one check each: the audit judged late joiners' claims against numbers they never saw. That was a fault in the audit, not in the game. The audit was corrected and both cases were run again (case 15: all 29 checks passed; case 5: the claim check passed, the only remaining failure is one number gap of 5.9 s against a 6 s limit, during a moment when the test computer itself dropped 34 calls).
- Scale games of 250, 500 and 1000 players (auto and Host): see the report. Eight "end-of-game report e-mail was sent" failures come from these older scale runs, which did not trigger the end-of-game step; the same check passes in every c25 game.
  `s1000h` (1000 players, Host) failed because 887 phones had not reached the end; its re-run `s1000h2` passed 26 of 27 checks.
- **10,000-player server test: NOT PASSED on this laptop.** With 10,000 simulated phones joining over 10 minutes and polling, the single local server stopped keeping up at about 8,000 joined: 2,025 joins failed and the answer time went above 27 s. The test program and the server share one laptop, so this shows the limit of this laptop, not of the live Cloudflare service, but it is not proof that 10,000 works. It has not been shown to work.

- **2,000-player server test: passed.** 2,000 joined over 2 minutes and polled for 2 minutes: 0 failed calls out of about 58,000. Answer time: join p50 74 ms / p95 436 ms; control p50 5 ms / p95 66 ms; seat list p95 96 ms. Database writes used: 6,000 (3 per player). The 10,000 run is the only size that failed on this laptop.

## Honest status against "six sigma by self"
- Measured: 14 failed checks of 725 judged (all explained above), which is about 19,000 per million, far from 3.4 per million.
- With this sample size, six sigma cannot be proven even with zero failures. It is **not certified**.
