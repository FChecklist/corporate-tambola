# QA matrix, 2026-10-23: every stage x every role, with the real-run evidence

Rule: a cell is GREEN only when a test run on the local copy (real Chrome pages, real clock, real public beacon) passed it, repeated 3 times. Anything else is OPEN.
"99.9999%" cannot be proven by sampling (that is 1 failure in a million 16-minute games); what is done instead is: every behaviour has a named check, every check passes 3 runs in a row,
every defect found is fixed and re-run, and the matrix below shows what is NOT yet proven.

## Defects found by this programme (and fixed)
1. Report said "All 90 numbers were called" for games that ended earlier (organizer's complaint). Fixed in lifecycle.ts, test added that fails on the old code.
2. A phone reloaded after the game ended by prizes showed numbers up to 90. Fixed (log cut at the last completion + 1), re-test in progress.
3. The countdown on a phone jumped backwards by 6 s (a stale clock answer). Fixed (newest of the last 5 answers).
4. Number screen showed one number less than the phones at the end by prizes. Fixed (same cut rule).
5. "Notify me" button covered the console's bottom bar on phones. Fixed.
6. Demo watermark covered ticket digits. Fixed (under the numbers, lighter).
7. /big before publishing: raw refused-call error. Fixed (plain message, no error report).
8. **Host first-open dead-end (present in the code that is LIVE today):** a Host who opens their personal link (`?e=GAME#host=KEY`) and types e-mail, code and mobile number is, on 3 of 4 tries, thrown to "This link no longer opens the game" in the middle of the setup, because a 5-second refresh asked for the game before the setup was finished. Found only by driving the Host screens like a person. Fixed (the game is not asked for until the setup is done). Probe: tools/host-setup-probe.mjs (live code 1 of 3 broken even when typing slowly, fixed code 0 of 4 broken).
9. A running game screen is never reloaded by the auto-update (it could cost a prize claim); it updates when the game is over, not started, or the page is in the background.
10. A countdown 9..1 is shown between numbers on the phone and on the number screen (no voice).
