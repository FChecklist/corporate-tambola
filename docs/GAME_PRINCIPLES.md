# Corporate Tambola: the game principles (owner, 2026-10-22)

These five rules decide every design question. Anything that breaks one of them is wrong, however convenient.

1. **We mimic real housie**, in both calling modes: the software calling at a steady speed, or a Host pressing "Next number". The order of the numbers always comes from the public random beacon; the mode only decides the pace.
2. **Zero cheating.** No person decides a winner or a number: not the organizer, not a Host, not us. Every phone works out the same result from public data, and a result stands only when enough different phones agree.
3. **Engagement.** Players see only the number just called, never the earlier numbers and never the board (the board is the organizer's alone). They must stay alert, as at a real housie table.
4. **Players cut and claim.** The ticket never marks itself. The player taps each called number, and wins a prize only by pressing Claim before the next number is called. A wrong claim is a Bogey; two Bogeys on the same prize and the ticket is out of that prize.
5. **Players are playing the game.** Nothing happens for a player who is not there: no automatic marks, no automatic claims, no prize for a complete ticket nobody claimed. The next valid claimant takes the position.

Everything else (prizes, tie rule, brand moments, Hosts, lists, payment, deletion of data within a day) serves these five.
