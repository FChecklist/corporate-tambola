How we keep it fair

Six plain facts for every player and every organizer.

  1. Nobody picks the numbers. Not the organizer, not the Host, not the Co-host, not the AI assistant and not us. Each number comes from a public random value that the whole world can see.
  2. Everyone gets the same number. The public random value is published every few seconds. Every phone in the game reads the same value, so every phone shows the same number at the same time. We never send you a number.
  3. Your phone checks it. Each public value carries a signature. Your phone checks the signature before it shows the number. A made-up number would fail the check.
  4. No one can know a number early. The value for each number is fixed by the game's schedule, before the value exists. Not even we can know the next number. A pause cannot be used to look at a number and then hide it.
  5. The software decides the winners. A prize goes to a valid Claim made in time, checked against the called numbers. A result counts only when several different phones agree. No person can choose, change or remove a winner. A wrong Claim is a Bogey and does not count.
  6. You can see what happened. The organizer gets a game log: every prize with its winning ticket, and every Claim with its time and what came of it. We keep the log for 365 days.
An honest limit. This makes cheating very hard, not impossible. In theory, very many people with many phones could agree on a false result. We say so because it is true.
